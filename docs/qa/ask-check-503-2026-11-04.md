# ASK Check answer availability — 2026-11-04

## Production diagnosis

- `https://clearn.me` responds with HTTP 200 and serves the static learner app.
- `https://clearn-api.onrender.com/api/health` responds with HTTP 503 and the Render message `Service Suspended: This service has been suspended.`
- Browser reproduction on ASK clarification exercises displays `Cannot reach the CLEARn API at https://clearn-api.onrender.com` after Check answer.
- Render suspension reason requires access to the service dashboard; it cannot be inferred from the public response.

## Fix

- The browser uses the same deterministic clarification checker as the API after a failed validation request.
- Expected answers, configured alternatives, normalization, and meaningless-input rejection are preserved.
- Feedback comes from the latest successfully loaded content, or the bundled snapshot.
- The API remains preferred when available. Its positive and negative results are returned unchanged.

## Verification

- 33 runtime regression cases pass: HTTP 502/503/504, network failure, timeout, configured feedback, content caching, primary API result, and existing ASK fallbacks.
- Clarification content/UI tests and real API tests pass.
- Shared input validation tests and API tests pass.
- Question formation API tests, exercise-template tests, syntax tests, and practice fallback tests pass.
- Client TypeScript check, API build, and production web export pass.
- Chromium smoke test of the production web export, with the API returning HTTP 503: correct answer accepted; incorrect answer rejected; two clarification requests intercepted; no page errors.

## Release blockers

- Render production API is still suspended. This change makes deterministic clarification checking resilient but does not resume the hosting service or restore server-only features.
- The existing production dependency audit fails: 65 high and 2 critical vulnerability records were reported, in addition to lower severities. No dependency manifests or lockfiles are changed by this fix.
- Per the deployment-readiness specification, production release must wait for dependency remediation and passing release checks. This branch is submitted as a draft PR, not deployed to production.
